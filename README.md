# オリジナルフォント＆ロゴ制作工房

iPad と Apple Pencil で、手書き文字・タイトルロゴ・装飾文字・オリジナルフォント（OTF）を作る Web アプリです。
サーバー・ログイン・API キーは不要で、作品や画像はすべて端末内（ブラウザの保存領域）で処理されます。

公開ページ：https://nyuriwossan.github.io/font-logo-workshop/

## できること

| 機能 | 内容 |
| --- | --- |
| 文字を描く（手書きモード） | Apple Pencil の筆圧を使った手書き、部分消しゴム・線ごと消しゴム、手ぶれ補正、入り・抜きの細さ |
| 文字を設計する（デザインモード） | 直線・ベジェ曲線・円・四角・多角形、塗り／線、制御点の編集、グリッド吸着、整列 |
| あとから直す | 選択・移動・拡大縮小・回転・反転・複製・グループ化。手書きの元データ（点と筆圧）を保存しているので、描いた後に線の太さや滑らかさも変えられます。手書き線を曲線に変換して制御点で直すこともできます |
| **パーツ再利用** | 線や図形を選んで「パーツに登録」→ パーツ棚から別の文字・ロゴへ挿入。貼り付けたものは元パーツから独立したコピーになり、元パーツを編集しても変わりません。パーツはプロジェクトをまたいで使えます |
| 文字セット | ひらがな・カタカナ・英大文字・英小文字・数字・記号・任意追加の漢字。作成済み／未作成の表示、検索、薄いお手本表示 |
| 字形の調整 | 大きさ・左右／上下の位置・送り幅（固定／字形に合わせて自動）・左右余白。プレビューで文字送りを確認 |
| ロゴ制作 | 任意の文字列、作成済み字形の自動使用、文字ごとの位置・回転・大きさ、文字間・行間、横書き・縦書き、色・グラデーション・縁取り・影・不透明度、図形や飾りの追加、複数レイヤー |
| 画像合成 | 写真・生成 AI イラストを読み込み、ロゴや文字を配置（移動・拡大縮小・回転・不透明度・重なり順・縁取り・影） |
| 書き出し | 透過 PNG・SVG・JPEG（合成）。範囲（全体／内容だけ＋余白）、倍率または幅指定、背景透明／色、プレビュー |
| フォント書き出し | 作成済みの文字だけで OTF（CFF アウトライン）を生成。出力前の検査、出力後の読み込み直し検証、試し書き |
| 保存 | 自動保存（IndexedDB）、複数プロジェクト（作成・名前変更・複製・削除）、JSON バックアップと復元（画像・パーツ棚込み） |

### 未作成の文字（代用文字）の扱い

| 場面 | 扱い |
| --- | --- |
| ロゴ編集画面 | 端末のフォントで代用表示。点線の枠で自作文字と区別（目印は出力されません） |
| PNG・JPEG | 代用文字も表示どおり画像化 |
| SVG | 自作文字はベクターパス。代用文字はその文字だけ PNG として埋め込み、SVG 内（コメントと `<desc>`）と書き出し画面で「完全なベクターではない」ことを明示 |
| OTF | 自分で制作・登録した字形だけを収録。代用文字は含めません |
| 差し替え | その文字を作ると、ロゴの代用文字は自動で自作文字に置き換わります（ロゴの「調整」→ 文字をタップ →「この文字を作る」） |

## iPad での使い方

1. Safari で公開ページを開き、共有ボタン →「ホーム画面に追加」から起動するのがおすすめです（データが消えにくくなり、オフラインでも起動できます）。
2. **Apple Pencil で描き、指で操作**します。Pencil を一度使うと、指は「移動・拡大」専用になります（手のひらの誤タッチ対策）。指でも描きたいときは「ツール」タブの設定で切り替えられます。
   - 2 本指でつまむ：拡大縮小と移動
   - 2 本指でタップ：1 つ取り消し
3. 上部の「文字／ロゴ／合成」で制作モードを切り替えます。文字画面の左上で「手書き／デザイン」を切り替えます。
4. 線や図形を選ぶと、画面上部に操作バー（複製・反転・整列・グループ化・パーツに登録・削除）が出ます。細かい数値は右パネルの「調整」タブで変えます。
5. メニュー（≡）→「保存とバックアップ」から、定期的に JSON バックアップを書き出してください。

キーボード（PC・Magic Keyboard）：⌘/Ctrl+Z 取り消し、⇧⌘Z やり直し、⌘D 複製、⌘G グループ化、Delete 削除、V 選択、P ペン、E 消しゴム、スペース＋ドラッグで移動、0 で全体表示。

## 開発・ビルド

Node.js 22 以上。

```bash
npm ci
npm run dev        # 開発サーバー
npm test           # ユニットテスト（Vitest）
npm run build      # 型チェック＋本番ビルド（dist/）
npm run preview    # ビルド結果の確認（http://localhost:4173）
```

E2E（受け入れテスト）は Playwright で、ビルドしたアプリを Chromium で操作します。

```bash
npm run build && npx vite preview --port 4173 &
npx playwright install chromium   # 初回のみ（または CHROME_PATH で Chromium を指定）
npm run test:e2e
```

### 公開（GitHub Pages）

`main` に push すると GitHub Actions（`.github/workflows/deploy.yml`）がテスト・ビルドして Pages に公開します。
リポジトリの **Settings → Pages → Source** を「GitHub Actions」にしておく必要があります。`vite.config.ts` の `base: './'` により、どのパスに置いても動きます。

## 設計

```
src/
  model/    編集データの型・既定値・文字セット・読み込み時の検証（normalize）
  geom/     行列、ベジェ、手書き線の外形（perfect-freehand）、輪郭の合体・差分（Clipper）、範囲・当たり判定
  render/   表示と出力：Canvas 描画、文字レイアウト、SVG 生成、PNG/JPEG 書き出し
  font/     OTF 生成と検証（opentype.js）
  store/    状態管理（zustand + immer）、取り消し履歴、IndexedDB 保存、バックアップ
  editor/   共通編集エンジン（入力・ツール・選択変形・パーツ操作）
  ui/       画面（パネル・ダイアログ）
```

- **編集データ・表示データ・出力データの分離**：保存するのは元の入力（手書きの点列と筆圧、ベジェのノード、文字列、変換行列）だけです。輪郭化・合体などの派生結果はキャッシュとして毎回計算し、保存しません。そのため、作った文字が後から編集できなくなることはありません。
- **1 つの編集エンジン**：文字・ロゴ・合成・パーツ編集は、同じオブジェクト構造（手書き線／パス／グループ／文字／ロゴ参照）と同じ編集エンジンを使います。
- **輪郭の一貫性**：字形は「全オブジェクトを非ゼロ規則で合体し、部分消しゴムを順に差し引いた単色輪郭」として計算し、同じ輪郭を OTF・SVG・ロゴ表示で使います。
- **パーツの独立性**：挿入時に深いコピーを作り ID を振り直します。将来の共有パーツ用に、パーツには登録元の位置（`origin`）を持たせています。
- **保存の確実性**：変更から約 0.7 秒後、またはアプリ切り替え時に IndexedDB へ保存し、トランザクション完了を待ってから「保存済み」と表示します。失敗時は赤い帯で明示し、再試行できます。読み込み時は壊れた部分だけを除外して残りを読み込みます。

## 動作確認結果（2026-10-18）

### 自動テストで確認済み

ユニットテスト 14 件（Node.js）と、受け入れテスト 40 項目（ヘッドレス Chromium 153、iPad Air 横向き相当の 1180×820・タッチ有効）がすべて合格しています。受け入れテストでは、Pencil 相当のポインターイベント（`pointerType: "pen"`、筆圧つき）で実際に描画しています。

- 文字制作：「あ」を手書きで作成・自動保存・再読み込み後に編集再開／描いた後の線幅変更／四角・円・曲線での文字制作／制御点の編集
- パーツ再利用：範囲選択→パーツ登録（ベクターのまま）→別の文字へ貼り付け→左右反転／元パーツを編集しても貼り付け済みデータが不変
- ロゴ・画像：複数文字の組み合わせ／自作文字と代用文字の区別／透過 PNG（角が完全に透明）／SVG（自作文字はパス、代用文字のみラスター埋め込みと明示、グラデーション・影・縁取りを保持）／代用文字から字形制作へ移動し自動で差し替え／背景画像の読み込み／ロゴ配置・回転・不透明度／合成画像の PNG（元画像サイズ）・JPEG／ロゴ部分のみの透過 PNG
- フォント：A・B・あ・い・お・漢 を Unicode に割り当てて OTF を出力／opentype.js で再読み込み（CFF 形式・名前・各字形の Unicode と輪郭数・送り幅）／字形のない文字（C・ん）が .notdef になる／ブラウザに読み込ませて A と B が別々の字形で描画される
- 保存：JSON バックアップ（画像・パーツ込み）→ 復元 → 復元したプロジェクトで編集、パーツ棚・背景画像の参照も復元／Undo・Redo／Pencil 検出後は指で描画しない／ページエラーなし
- 補足：iPhone 幅（390px）での表示と、2 本指ピンチでの拡大も確認しました

## 既知の制約

- TTF 形式の書き出しには対応していません（OTF の品質を優先）。
- フォントには縦組み用の情報（vhea/vmtx）を入れていません。ロゴ画面の縦書きには対応しています。縦書きでは句読点の位置ずらしと、長音・括弧などの 90° 回転だけを行っています。
- フォントの輪郭は細かい折れ線（直線の連続）で、曲線（ベジェ）には変換していません。見た目は滑らかですが、ファイルは大きめになります（1 文字あたり数百バイト〜数 KB）。
- カーニング（文字の組み合わせごとの詰め）には対応していません。
- 部分消しゴムは文字・パーツ画面のみです。ロゴ・合成では「線ごと消す」消しゴムになります。
- 代用文字の見た目は端末のフォントに依存します（iPad ではヒラギノ角ゴシック）。フォントファイルは同梱していません。
- 書き出しは iPad Safari の Canvas 上限（約 1,670 万ピクセル）を超えないよう、自動で縮小します。
- ブラウザによっては日本語のファイル名が無視されるため、書き出すファイル名は半角英数字（例：`logo-20261018-221530.png`）にしています。
- 端末内保存はブラウザのデータ消去などで消える可能性があります。JSON バックアップを定期的に書き出してください。
- 筆圧以外の Apple Pencil 固有機能（ダブルタップ、ホバー、スクイーズ）は使っていません。
